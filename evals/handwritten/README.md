# Recetas manuscritas

Una por persona, M1 a M8, según el reparto del plan de ejecución. Cada quien escribe a mano una receta con paciente inventado, la fotografía con el teléfono y la guarda como `M1.jpg` ... `M8.jpg`.

`etiquetas.jsonl` guarda, por foto, lo que realmente dice: paciente, edad, medicamento, dosis, frecuencia, duración y el resultado esperado (`rutina`, `alto_riesgo`, `ambiguedad` o `ilegible`) que fija `plan_golden.csv`.

Niveles de legibilidad según el reparto: M1, M2 y M3 leve; M4, M5 y M6 media; M7 y M8 severa (escritura apurada, foto oscura o inclinada).
